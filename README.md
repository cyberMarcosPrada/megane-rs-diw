
# Renault Megane III R.S.

## Autor
[Marcos y Prada Arévalo]


## Descripción
Desarrollo de una página web dedicada al Renault Megane III R.S.

El proyecto presenta información sobre el vehículo, sus especificaciones técnicas, las diferentes versiones y una galería de fotografías.

La página está diseñada para adaptarse a dispositivos de escritorio y móviles.

## Tecnologías utilizadas
- HTML5
- SASS / SCSS
- JavaScript
- Vite

## Instalación y ejecución

1. Instalar las dependencias:

   npm install

2. Iniciar el servidor de desarrollo:

   npm run dev

3. Compilar el proyecto:

   npm run build

4. Visualizar la versión compilada:

   npm run preview

La versión de producción se genera en la carpeta `docs`.
